# Conteúdo de terceiros

A licença do repositório ([LICENSE](LICENSE)) cobre o **código e os materiais do autor**. Os itens abaixo vêm de terceiros ou têm origem própria e **cada um segue a sua licença**. Quem redistribui ou transmite o jogo é responsável por verificar se pode usá-los.

| Item | Onde | Observação |
|---|---|---|
| Animações de dança (Flair, Rumba Dancing) | `game/assets/dances/` | Vêm do **Mixamo** (Adobe). Os termos do Mixamo permitem usar em projetos, mas **não** redistribuir as animações isoladamente. |
| Músicas (`jamal.mp3`, `confidenceholic.mp3`) | `game/assets/music/` | Montagens musicais de terceiros: **verifique os direitos autorais** antes de usar na live ou de redistribuir. Troque por músicas livres se tiver dúvida (basta substituir os arquivos mantendo o nome). |
| Modelos 3D (personagem, palmeira, ilha, rochas, grama) | `game/assets/models/` | Origens e autorizações indicadas pelo autor. Confira as licenças originais. |
| Céu, texturas | `game/assets/sky/`, `game/assets/textures/` | Idem. |
| Personagem do prompt padrão | `server/config/persona.md` | O prompt padrão imita um personagem de uma franquia conhecida (marca registrada de terceiros). Para publicar uma live própria, **troque pela sua personalidade** na aba *Personagem* do painel. |
| Voz de referência | `server/assets/voice/` (não vai no Git) | Use **apenas vozes que você tem autorização para usar**. |
| XTTS v2 | opcional, baixado à parte | **Coqui Public Model License** (uso não comercial). |
| Chatterbox | opcional, baixado à parte | MIT. |
| Godot Engine | `Live3D.exe` | MIT ([godotengine.org/license](https://godotengine.org/license)). |
| tiktok-live-connector, ws, socks-proxy-agent | `server/package.json` | Bibliotecas de código aberto (veja as licenças de cada uma no npm). |

Este projeto não é afiliado ao TikTok, OpenAI, Google, ElevenLabs, Mixamo ou Adobe.
